PolyBot Archive

A private desktop uploader for preserving the owner's historical files in their own Google Drive.

Purpose

The uploader transfers explicitly selected archives and restoration metadata. It checks file integrity after upload and keeps local archives unless the owner separately chooses to remove them.

Limited Google Drive access

The application requests the drive.file permission. It can manage files created by, or explicitly selected for use with, this application. It does not request unrestricted access to the owner's entire Drive.

Personal use only

This is a personal utility, not a public backup service. This website contains application information only. It does not host archives, provide a sign-in form, or accept file uploads.

Privacy and control

Archives stay in the owner's private storage. Access can be revoked from the owner's Google Account connections. Read the privacy policy for data handling, retention, and control details.
